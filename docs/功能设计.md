# LoRa 温度监测系统 - 功能设计文档

> 版本：v1.1.0  
> 更新日期：2026-07-27  
> 适用硬件：LoRa 温度集中器 + 无线温度传感器（ID1~5）+ 无线压力传感器（ID6）

---

## 一、系统概述

本软件是基于 Qt6 的跨平台桌面应用，通过串口 Modbus RTU 协议与 LoRa 集中器通信，实时采集多点无线温度传感器和无线压力传感器的数据，提供卡片、曲线、表格三种可视化视图，自动记录到 CSV 文件，并支持温度上下限报警。

## 二、功能模块详细设计

### 2.1 串口配置模块

**位置**：左侧配置面板顶部

| 配置项 | 控件 | 默认值 | 可选范围 |
|--------|------|--------|----------|
| 串口 | QComboBox + 刷新按钮 | 自动检测 | 系统可用串口 |
| 波特率 | QComboBox | 9600 | 9600/19200/38400/57600/115200 |
| 从机地址 | QSpinBox | 1 | 1~247 |
| 起始ID | QSpinBox | 1 | 1~200 |
| 节点数 | QSpinBox | 2 | 1~16 |
| 采样周期(ms) | QSpinBox | 2000 | 500~60000，步进 500 |
| 压力传感器ID | QLineEdit | "6" | 逗号分隔的ID列表 |
| CSV目录 | QLabel + 选择按钮 | `<appdir>/data` | 任意可写目录 |

**特性**：
- **串口刷新**：打开软件后插入 USB 串口时，点击"刷新"按钮可重新扫描可用串口列表，并尝试恢复之前选中的串口
- **CSV目录策略**：默认使用可执行文件目录下的 `data` 文件夹；用户可点击"选择..."自定义目录，通过 `csvDirUserSet` 标志区分用户选择与默认值，确保移动/重装后仍能正确解析
- **配置持久化**：所有配置通过 QSettings 保存，下次启动自动恢复

### 2.2 数据采集模块（ModbusWorker）

**位置**：子线程运行，避免阻塞 UI

#### 2.2.1 Modbus RTU 协议参数

| 参数 | 值 |
|------|-----|
| 功能码 | 0x04（读输入寄存器） |
| 从机地址 | 1（集中器地址） |
| 串口格式 | 9600 bps / 8 数据位 / 1 停止位 / 无校验 |
| 超时 | 1000 ms |

#### 2.2.2 寄存器映射

**温度寄存器**（所有节点都读）：
- 起始地址：`0x76C1`（30337）
- 每节点 1 个寄存器
- 节点 N 地址 = `0x76C1 + (N-1)`
- 数据格式：16 位有符号整数（补码，大端），÷10 得摄氏温度
  - `0x00BF` (191) → 19.1 ℃
  - `0xFF60` (-160) → -16.0 ℃

**压力寄存器**（仅压力节点读取）：
- 起始地址：`0x8EF9`（36601）
- 每节点 2 个寄存器（32 位无符号整数）
- 节点 N 地址 = `0x8EF9 + 2×(N-1)`
- 数据格式：2 个 16 位寄存器组合成 32 位无符号整数，单位 Pa
  - `0x000F 0x4240` → 1000000 Pa
- ID6 压力地址 = `0x8F03`（36611）

#### 2.2.3 采集流程

```
onTimeout() 触发：
  ├── 为每个节点（startId ~ startId+nodeCount-1）预创建默认 Sample
  ├── 所有节点发送温度读取请求（1 个寄存器）
  ├── 压力节点额外发送压力读取请求（2 个寄存器）
  └── 等待所有 reply.finished()

onReplyFinished()（每个应答触发一次）：
  ├── 根据 readType 区分温度/压力
  ├── 温度应答：更新 Sample.tempCelsius / raw / alarm
  ├── 压力应答：更新 Sample.pressurePa，打印原始帧日志
  ├── m_pendingReplies--
  └── 当 m_pendingReplies==0：emit dataReady(所有 Sample)
```

**关键设计**：
- **压力节点同时保留温度值**：压力传感器内部有温度探头，软件同时读取温度寄存器和压力寄存器，合并到同一个 Sample
- **聚合机制**：使用 `QHash<int, Sample>` 按 nodeId 聚合同一轮的多个应答，所有应答到齐后统一上报
- **失败计数**：连续 3 次通讯异常才 emit error，避免偶发错误刷屏
- **QTimer 创建时机**：在子线程的 `start()` 中动态创建 QTimer，避免"主线程创建+子线程运行"导致的事件绑定错误

#### 2.2.4 运行时参数调整

| 参数 | 调整方式 | 生效时机 |
|------|----------|----------|
| 采样周期 | UI SpinBox | 立即（通过 `Qt::QueuedConnection` 转发到子线程） |
| 起始ID/节点数 | UI SpinBox | 立即重建卡片/选择器/曲线 |
| 压力传感器ID | UI QLineEdit | 立即重建卡片/选择器 |
| 报警阈值 | UI DoubleSpinBox | 立即（下次采集就用新值） |

### 2.3 数据展示模块

#### 2.3.1 数据卡片（左侧下方）

- **网格布局**：2 列 × 4 行，共 8 个卡片
- **显示内容**：
  - 温度节点：`IDx 温度` 标题 + `xx.x ℃` 数值
  - 压力节点：`IDx 压力` 标题 + `xx.xxx kPa` + `xx.x ℃`（双行显示）
- **状态指示**：
  - 在线正常：灰色背景 `#f5f5f5`
  - 超上限：红色背景 `#c0392b`，白色文字
  - 超下限：蓝色背景 `#2980b9`，白色文字
  - 离线：显示 `--`，灰色文字
  - 未配置节点：显示 `无`，暗色背景 `#ececec`

#### 2.3.2 实时曲线（右上方）

- **图表库**：Qt Charts（QChart + QLineSeries）
- **X 轴**：时间轴（QDateTimeAxis），格式 `HH:mm:ss`，显示最近 5 分钟，11 个刻度（每格 30 秒）
- **Y 轴**：温度轴（QValueAxis），范围 -20~80 ℃
- **曲线**：最多 8 条，每节点一条，颜色唯一
- **点数限制**：每条曲线最多 900 个点（30 分钟 @ 2 秒采样），超出后丢弃最旧的点
- **颜色方案**（8 种唯一色，色相均匀分布）：

| ID | 颜色 | 色值 |
|----|------|------|
| 1 | 红 | `#e74c3c` |
| 2 | 橙 | `#e67e22` |
| 3 | 黄 | `#f1c40f` |
| 4 | 绿 | `#27ae60` |
| 5 | 青 | `#00bcd4` |
| 6 | 蓝 | `#2980b9` |
| 7 | 紫 | `#8e44ad` |
| 8 | 粉 | `#e91e63` |

- **高度比例**：图表高度:表格高度 = 3:2（图表是表格的 1.5 倍，满足 1.2~1.8 倍要求）

#### 2.3.3 ID 选择器（曲线下方）

- **网格布局**：4 列 × 2 行，共 8 个复选框
- **每个选择器**：颜色色块（16×16）+ 复选框（`IDx`）
- **颜色与曲线一致**：色块颜色 = 该 ID 的曲线颜色
- **默认勾选**：当前节点数范围内的 ID
- **交互**：勾选/取消立即显示/隐藏对应曲线

#### 2.3.4 数据表格（右下方）

- **列定义**：6 列

| 列 | 标题 | 内容 | 示例 |
|----|------|------|------|
| 0 | 时间 | HH:mm:ss.zzz | 14:30:01.123 |
| 1 | 节点 | 节点 ID | 6 |
| 2 | 温度(℃) | 所有节点温度 | 24.1 |
| 3 | 压力(Pa) | 仅压力节点 | 1000000 |
| 4 | 原始值 | 寄存器原始值（HEX） | 0x00BF |
| 5 | 报警 | 报警状态 | 正常/超上限/超下限 |

- **行数限制**：最多 500 行，超出后删除最旧行
- **插入方式**：顶部插入，最新数据在最上方

#### 2.3.5 日志框（底部，全宽）

- **高度**：固定 120px
- **字体**：等宽字体（Monospace）
- **行数限制**：最多 500 行
- **日志类型**：

| 类型 | 示例 |
|------|------|
| 操作日志 | `[14:30:01.123] 应用启动` |
| 采集开始 | `[14:30:02.456] 开始采集 \| 串口=ttyUSB0 波特率=9600 ...` |
| 报警日志 | `[14:30:05.789] [报警] ID3 超上限: 65.2℃` |
| 配置变更 | `[14:30:10.012] 报警下限已更新为 -5℃ (全局生效)` |
| Modbus 帧 | `[14:30:03.456] [发送] ID6 压力请求: 01 04 8F 03 00 02 AB 1F` |
| Modbus 帧 | `[14:30:03.567] [接收] ID6 压力应答: 01 04 04 00 0F 42 40 FA D7` |
| 错误日志 | `[14:30:15.234] [错误] 通讯异常: 请求发送失败` |

**注意**：日志框**不显示**采集到的数据（避免刷屏），只显示操作、报警、Modbus 帧和错误。

### 2.4 报警模块

- **阈值类型**：全局共享（所有节点用同一组上下限）
- **默认值**：下限 -10 ℃，上限 60 ℃
- **配置范围**：-100.0 ~ 200.0 ℃，步进 0.5，1 位小数
- **防呆**：下限不能超过上限，上限不能低于下限
- **生效时机**：实时（修改 SpinBox 立即生效，下次采集就用新值）
- **报警判定**：仅对温度值判定，压力值不参与报警
- **持久化**：通过 QSettings 保存

### 2.5 CSV 数据记录模块

- **文件名**：`temp_YYYYMMDD_HHMMSS.csv`
- **编码**：UTF-8 with BOM（Excel 友好）
- **目录**：默认 `<appdir>/data`，可用户自定义并持久化
- **写入时机**：每次收到 `dataReady` 信号立即写入并 flush
- **列定义**：

| 列 | 说明 | 示例 |
|----|------|------|
| timestamp | 采集时间 | 2026-07-27 14:30:01.123 |
| node_id | 节点 ID | 6 |
| temp_celsius | 温度（℃），所有节点都有 | 24.1 |
| pressure_pa | 压力（Pa），仅压力节点，温度节点为空 | 1000000 |
| raw | 寄存器原始值（HEX 大写） | 0X00BF |
| online | 在线状态 | 1 |
| alarm | 报警状态 | 0=正常 / 1=超上限 / -1=超下限 |

### 2.6 配置持久化模块

- **存储方式**：QSettings（IniFormat）
- **存储位置**：
  - Linux：`~/.config/LoRaTemperature/LoRaTemperature.conf`
  - Windows：注册表 `HKEY_CURRENT_USER\Software\LoRaTemperature\LoRaTemperature`

**可持久化配置项**：

| 键 | 说明 |
|----|------|
| `serial/portName` | 串口名 |
| `serial/baudRate` | 波特率 |
| `serial/dataBits` | 数据位 |
| `serial/stopBits` | 停止位 |
| `serial/parity` | 校验位 |
| `serial/slaveAddr` | 从机地址 |
| `node/startNodeId` | 起始节点 ID |
| `node/nodeCount` | 节点数 |
| `node/samplePeriodMs` | 采样周期 |
| `node/tempRegAddr` | 温度寄存器地址 |

## 三、数据结构

### 3.1 Sample（采集样本）

```cpp
struct Sample {
    qint64  timestampMs;   // 采集时间戳（epoch 毫秒）
    int     nodeId;        // 节点 ID（1~16）
    quint16 raw;           // 寄存器原始值
    qreal   tempCelsius;   // 解析后温度（℃），所有节点都有
    qreal   pressurePa;    // 解析后压力（Pa），仅压力节点有效
    bool    isPressure;    // true=压力传感器，false=温度传感器
    int     online;        // 1=本次成功读取，0=未读到
    int     alarm;         // 0=正常，1=超上限，-1=超下限
};
```

### 3.2 AppConfig（应用配置）

见 2.6 节配置项列表，关键成员：
- `pressureNodeIds`：QString，逗号分隔的压力传感器 ID 列表
- `parsedPressureNodeIds()`：解析为 `QSet<int>`
- `isPressureNode(int id)`：判断节点是否为压力传感器
- `pressureRegAddrForId(int id)`：计算节点 N 的压力寄存器起始地址

### 3.3 解析函数（纯函数）

```cpp
// 温度解析：quint16 → qint16 补码 → /10.0
qreal parseTempCelsius(quint16 raw);

// 压力解析：2 个寄存器 → 32 位无符号整数 → Pa
qreal parsePressurePa(quint16 high, quint16 low);

// 报警判定：0 正常 / 1 超上限 / -1 超下限
int checkAlarm(qreal temp, qreal low, qreal high);
```

## 四、模块间通信

### 4.1 信号槽连接

| 信号源 | 信号 | 槽 | 连接类型 |
|--------|------|----|----------|
| MainWindow | `m_startBtn::clicked` | `onStart()` | DirectConnection |
| MainWindow | `m_periodSpin::valueChanged` | lambda → `m_worker::setSamplePeriod` | QueuedConnection（跨线程） |
| ModbusWorker | `dataReady(QVector<Sample>)` | `MainWindow::onDataReady` | QueuedConnection（跨线程） |
| ModbusWorker | `error(QString)` | `MainWindow::onError` | QueuedConnection |
| ModbusWorker | `statusMessage(QString)` | `MainWindow::onStatus` | QueuedConnection |
| ModbusWorker | `frameLog(QString)` | `MainWindow::appendLog` | QueuedConnection |

### 4.2 跨线程类型注册

```cpp
qRegisterMetaType<QVector<Sample>>("QVector<Sample>");
qRegisterMetaType<AppConfig>("AppConfig");
```

### 4.3 生命周期管理

- `ModbusWorker` 通过 `QThread + moveToThread` 运行在子线程
- `QThread::finished` 信号连接到 `QObject::deleteLater`，确保线程退出时清理 worker
- 析构时：先 `stop()` worker，再 `quit()` + `wait()` 线程，最后关闭 CSV 并保存配置

## 七、使用流程

1. **连接硬件**：USB 转 RS485 → LoRa 集中器；集中器已注册温度传感器（ID1~5）和压力传感器（ID6）
2. **启动软件**：`./build/src/LoRaTemperature`
3. **选择串口**：左侧配置面板选择 USB 转 RS485 对应的串口（如 `ttyUSB0`）
4. **配置参数**：
   - 起始 ID：`1`
   - 节点数：`6`（覆盖 ID1~6）
   - 压力传感器 ID：`6`
   - 采样周期：`2000` ms
   - 报警阈值：下限 `-10`℃，上限 `60`℃
5. **点击"开始"**：
   - 自动创建 CSV 文件 `<appdir>/data/temp_YYYYMMDD_HHMMSS.csv`
   - 日志框显示开始采集信息和压力传感器 ID
   - 卡片开始更新数值
   - 曲线开始绘制
6. **观察数据**：
   - 左侧卡片：ID1~5 显示温度，ID6 显示压力+温度
   - 右上曲线：最多 8 条温度曲线，可通过 ID 选择器控制显示
   - 右下表格：最近 500 条历史记录
   - 底部日志：操作日志、报警日志、Modbus 帧
7. **点击"停止"**：关闭 CSV 文件，可用 Excel 打开查看

## 八、已知限制与扩展方向

### 8.1 当前限制

- 最多支持 8 个节点（受 UI 卡片和 ID 选择器布局限制）
- 压力传感器不参与报警判定（仅温度报警）
- 曲线仅显示温度，不显示压力曲线
- 报警阈值为全局共享，不支持按节点单独配置

### 8.2 扩展方向

- 支持更多节点（扩展卡片为滚动布局）
- 增加压力曲线（双 Y 轴）
- 支持按节点配置报警阈值
- 增加数据导出功能（导出指定时间范围）
- 增加远程报警通知（邮件/短信）
- 增加传感器在线状态诊断（读取 0x7531 寄存器）
